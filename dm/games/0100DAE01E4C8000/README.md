# STORY OF SEASONS: Grand Bazaar (`0100DAE01E4C8000`)

<!-- PEANUTS: a Peanuts Native profile and note (Banana Native has none for this title). -->

Update v655360 over the base game (the dump carries no display version). SDK 18.3.5. Unity 2020.3 IL2CPP with CRIWARE and FMOD, NVN graphics. Modules `main`, `subsdk0` (NintendoSDK_movie) and `sdk`. The NPDM declares 16 MB of system resource: the game maps its own memory and sets no heap.

**Status (current): boots and reaches character creation on Android.** On an AYN Thor (Adreno 740, Turnip 27.0.0 R2, 2026-11-18) it boots, passes the title and new game, and shows the Choose Look screen with its 3D character at 30 fps; 128 draws a frame, every pipeline made, no crash. Not run on Qualcomm's system driver yet, nor further into the game. The profile is the survey's guess (`dm/games/profile_guess.py`) plus a measured `mem_used`.
