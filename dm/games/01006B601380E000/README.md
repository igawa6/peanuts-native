# Kirby's Return to Dream Land Deluxe (`01006B601380E000`)

<!-- PEANUTS: a Peanuts Native profile and note (Banana Native has none for this title). -->

Base game 1.0.0 (v0), no update known. SDK 13.3.5. HAL Laboratory's own engine on NintendoWare (G3d, Font, Ui2d, Vfx2, Fxt 1.57.0) with NVN graphics. Same engine family as [Kirby and the Forgotten Land](../01004D300C5AE000/README.md), whose note covers the engine. Modules `main`, `subsdk0` (NintendoSDK_movie, the WebM movie module) and `sdk`.

**Status (current): plays on Android.** On an AYN Thor (Adreno 740) it boots, passes the title and the file select, and plays the first stage, on the system driver and on Turnip 27.0.0 R2, with the firmware's shared fonts (without them it crashes at startup, below). Not run on the Mac. The profile started as a provisional one; its memory layout is still the guess below.

The companion of eden-duo-companions (package `KirbysReturnToDreamLandDeluxe`, build FA24EA3C3A512C07, this base build) loads and shows its stage page (lives, Point Stars, Pause, Drop Ability) on the Thor's second screen.

## Frame rate

- **Current (Turnip, first stage):** the overlay shows 60 fps, but 158 to 162 of every 300 frames take longer than 16.7 ms (p99 about 20 ms), so the game runs at 50 to 60 fps. Not profiled yet.

## Found on this game

- **Resolved: startup crash without firmware fonts (Android).** With no firmware in the app, the host serves Android's fallback font for every shared font type, which lacks U+25A1; right after nnMain the game dereferences a null glyph and crashes (`CRASH sig=11 addr=0x38 pc=main+0x4a78c8`, `x1=0x25a1`), as [Echoes of Wisdom](../01008CF01BAAC000/README.md) does. The game's own fault, not the host's: the fix is the firmware's shared fonts, and the launcher's font gate (`dev.peanuts.ui.FontGate`, `NEED_FONTS`) now holds this title back without them.
