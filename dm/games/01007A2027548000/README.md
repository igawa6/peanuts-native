# Trails in the Sky 2nd Chapter (`01007A2027548000`)

<!-- PEANUTS: local Android bring-up profile. -->

Switch update 1.0.3 (`v327680`), Nintendo SDK 21.4.4, ARM64, NVN. `main` imports Nintendo's movie module (`subsdk0`); the host supplies `rtld`. The NPDM declares 16 MiB of system resources. Before `nnMain`, the game requests a `0x81200000`-byte heap and an `0x2d1400000`-byte address region after roughly 1 GiB of SDK allocations. The profile reserves 2.25 GiB for the heap and 16 GiB of virtual address space for alias mappings; the provisional 128 MiB heap and 4.375 GiB alias caps stopped startup.

**Android status: bring-up.** Native boot, controllable gameplay in Rolent, audio, saving and manual reload were exercised on a Retroid Pocket Flip 2 (Adreno 650, Turnip T30). At unchanged graphics settings, the rebuilt Vulkan pack measured 48.40 displayed FPS over 67.827 seconds at the Rolent gate (2,496 single-refresh and 787 double-refresh intervals), up from about 35 before the pacing change below. Locked 60 FPS and texture stability throughout the city are not verified. Use a dump with update 1.0.3. The default Android profile roster includes Trails; pass `-PnxGames=01007A2027548000` for a Trails-only build. The base release is not registered.

## Rewrite and shaders

- The full 1.0.3 scan covers 134,631 RomFS files and finds 11,340 unique shaders: 2,116 vertex, 9,181 pixel and 43 compute. `shader_files.tsv` keeps every shader-bearing file for the Android targeted split, including copies not named in the map.
- `main+0x34ae60` branches to its own store-exclusive. The Android rewriter relocates that branch within the exclusive window; the occupied path executes `clrex` before branching out.
- RomFS `.nvn` files and `main` contain GLSLC outputs. [One compute output's code starts past its nominal control length](../../../docs/reference/shaders.md#glslc-outputs-in-main-and-in-loose-files). The splitter reads the section offset to recover its code header instead of passing constant data to the translator.
- The game reads the texture builder's depth/stencil mode during startup. The host returns the builder's stored aspect rather than the unimplemented dispatch's zero return.
- With a fresh Vulkan pipeline cache, loading the Rolent save skipped 11,780 draws. Prewarming 494 pipeline keys recorded on the Flip 2 (460 graphics, 34 compute) reduced that to zero on the same load. This source profile does not ship the binary seed; the result applies only to the seeded run.
- Turnip needs a render-pass boundary after the D16 shadow-cache stitch (`eb824d256484ca7f`), before the subsequent casters test against its depth. On the Flip 2, the combined pass produced intermittent checkerboard shadows on Elize Highway; the split produced zero flashes in 2,833 captured frames. Both draws and the original graphics settings are retained.
- On the Thor (Adreno 740, Balemuni Apex V2), a different Elize Highway flicker starts in the terrain geometry pass: the interpolated normal turns sideways in staggered 16-pixel squares when the camera rotates. The single-sample terrain pipeline uses centroid interpolation for its normal input only. It retains the original textures, mip selection, shadows and resolution. Restoring the original shader reproduced the grid; the release build showed no matching flash in a 4,397-frame camera sweep and averaged 58.93 displayed FPS.
- On the tested Turnip T30 build for Adreno 650 with host-signalled timelines, skip only the present thread's CPU wait before taking the queue lock. The Vulkan submission still waits for the frame's timeline value. In Rolent, this removed the Android producer wait under the queue lock; `DM_VK_PRESENT_PREWAIT=1` restores the prior behavior.
- The tested T30 driver reports 33.11 ns per GPU timestamp tick on the Adreno 650; calibration against elapsed time gives 52.08 ns. With the corrected units, the gate took 19.25 ms of GPU work per frame in a 60-frame sample, over the 16.67 ms budget for native 60 FPS. The measured city walk from the rebuilt pack started with an empty pipeline cache: all 494 seed entries compiled, with no asynchronous draw skips or texture-cache evictions observed through the walk. The stock Flip 2 Qualcomm driver does not meet the Vulkan readiness checks for this renderer.
- Experimental TurnipZ 0.4.0 reached 57.98 displayed FPS at the gate with classic passes and inline command encoding. At the garden, larger encoder batches with forced system-memory rendering reached 52.57 displayed FPS; a 60-frame sample still took 18.47 ms on the GPU and 18.90 ms to record. These are measurements, not a shipped driver or preset. The garden's main geometry and deferred-outline passes remain the largest measured GPU costs (about 5.1 and 3.8 ms).
