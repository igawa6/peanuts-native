# Kingdom Hearts Final Mix

Program **1** of *Kingdom Hearts HD 1.5+2.5 ReMIX*, base v0 (1.0.0). The member's `main.npdm` identifies `010090C022978001`; the collection menu is program 0 (`010090C022978000`), and [Kingdom Hearts II Final Mix](../010090C022978003/README.md) is program 3. They have different `main` builds even though their SDK modules match. This profile is for code preparation, not an Android playability listing.

With a dump folder containing program 0 (`base/exefs`, `base/romfs`) and program 1 (`base/program/1/{exefs,romfs}`), run `python scripts/pack_android.py <dump> --program 1`. This writes the complete Android pack without extracting or distributing shader modules. The member's RomFS contains 17 files (7,586,936,221 bytes), including `kh1_first.pkg`. A program-0-only `.nup` cannot supply either the member's code or its RomFS. For the Android test launcher, add a folder containing only this member beside program 0, so the first supported program is unambiguous.

All 48 embedded modules (26 vertex, 22 fragment; 46 distinct hashes) validated with `spirv-val --target-env vulkan1.0`. These are not NVN shader-map entries.
