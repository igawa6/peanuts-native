# Battle Brothers (`0100C5000F294000`)

<!-- PEANUTS: a Peanuts Native profile and note (Banana Native has none for this title). -->

Update 1.14.0 (v917504) on the base game. SDK 13.3.2. Overhype Studios' own engine: the game logic is Squirrel 3.0.4 scripts in the RomFS (`data/scripts/*.nut`), the interface NoesisGUI (`noesis/*.xaml`), with NVN graphics. Modules `main` and `sdk`.

**Status (current): plays on Android.** On a Motorola signature (Adreno 829, 11.0 GiB of RAM as the launcher reports it, Android 17) with Turnip Gen8 V39 (Mesa 27.0.0-devel, driver ID 18) it boots to the title menu, starts a new campaign, saves, loads a save and plays the campaign on the world map at 60 fps, with the nine add-ons (`0100C5000F295001` to `0100C5000F295009`) found by the game. It also boots and plays on the phone's system driver (Qualcomm; its version was not recorded). Not run on the Mac. No companion: eden-duo-companions has none for this title.

## Memory

The game sets a 2.68 GB heap in the profile's 2.75 GB heap region (`[mem] heap 2.68 GB (heap region 2.75 GB)`), with no heap or address-region failure in the log.

## Frame rate

- **Current (Turnip, Docked output 1080p, FSR 1):** 60 fps in the menus and on the world map, also at the widest zoom. On the title menu the phone's overlay showed CPU 9 %, GPU 10 %.
- The game paces itself at 60. With the launcher's default cap the host logs `[nvn] present cap 60 fps not applied: this main has neither a frame step nor an engine frame limit`; the lower caps the launcher offers (30, 20, 15) were not tried.

## Found on this game

- **Tip: add-ons and a pack made on a computer.** `pack_android.py` lists the add-ons in the pack (`aoc` rows) from the dump folder's `dlc/`. A pack made from a dump folder that holds only the update has none, and the game says "This DLC is missing" although the launcher lists the add-ons; make the pack from a dump or `.nup` that holds them.
